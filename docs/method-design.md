### 1.2 决策时机（设计点 1）

| 模型 | 决策时刻 | 取舍 |
|---|---|---|
| **事件驱动（推荐）** | 机器空闲/工件到达/故障发生时触发 | 贴近真实车间（[10][12] 为主流做法）、样本效率高 |

### 1.6 Episode 定义

一个 episode = 一个工厂场景：**1 次参数化布局采样 + 1 条扰动流 + 一批工件**。布局 seed 可记录 → 训练可复现（采样器确定性），消融公平性白拿。

## 2. 表征层设计

### 2.1 分层数据流（布局生成与路网计算的职责边界——必须写清）

```
① 布局生成层（产"哪里有东西"）           ② 路网/物理层（产"往哪走、走多远、会不会撞"）
   输入：机器数/布局类型/暂存容积/通道宽度   输入：①的机具脚印+通道轮廓 + 车辆半径/车速表
   输出：点集（位置/尺寸/属性表）          输出：走廊图 G=(V,E)（路点+边长）
         → 机台/暂存区/充电桩/通道              → A*（networkx）距离矩阵
   核心模型：参数化布局采样器（Parametric         输出：碰撞/死锁事件（SimPy zone 层建模；
           Layout Generator，同 seed 同点集）         正文不引入物理库）
        ▼                                    ▼
        └─────────► ③ 特征提取层 → layout_descriptor.json ◄─────────┘
                   world 段 ← 布局点集/属性        nav 段 ← 路网距离矩阵
```

**训练与部署共用 ③**（描述器 schema 来源无关）——这才是"零样本"成立的机制保证。

    "charging": [{id, pos}],
    "aisle_width": 2.8, "char_len": 43.2
  },
  "nav": {                              // ← 来源：走廊图 + A*（networkx）
    "pts_on_network": {"machines": [...]},
    "dmatrix": [[0, 12.4, 18.1], ...],  // 机台↔机台最短路距离，每个布局预计算并缓存

```

### 2.2 Token 与几何不变特征

**不变性四规则**（跨布局成立的全部依据）：

| 不变性 | 做法 |
|---|---|
| 平移 | 只用差值/相对量，不喂绝对 xy |
| 旋转 | 所有位置投影到 **PCA 主轴坐标系**（工厂转 90° 仍是同一拓扑） |
| 缩放 | 距离 ÷ **char_len**（包围盒对角线/机台平均间距） |
| 拓扑 | Token 数随规模变化（可变长注意力）+ 特征均为相对统计量 |

**各 Token 追加特征**：

```
Machine Token: + 挂载点主轴坐标(u,v) + d(m,hub) + d(m,buffer) + 走廊宽度/瓶颈度
             + 进站缓冲占用率 / 出站缓冲占用率（in/out-buffer 显式建模，[12] RCIM 先例；
               缓冲满=阻塞源，与占道率共同构成拥堵表征——此前遗漏，2026-09-04 补）
Vehicle Token: + 当前路点主轴坐标 + d(v,pickup) + d(v,dropoff) + 速度/负载/电量/弯道标志
Global Token:  + 机台数/车数 + 距离矩阵均值/方差 + 全线占道率（拥堵为"匿名化"计数，
                 不绑定车辆 ID/路线，防记忆路线）
```

**几何注意力偏置**（让注意力"看得见距离"）：

```
AttnScore(i,j) = q_i·k_j/√d + b(i,j)
b(i,j) = w_d·(d_ij/char_len) + w_c·conf_sim(i,j)
```

三个必守规则：① 归一化**必须每次 episode 内做**（per-instance normalization）；② 布局分布须覆盖部署拓扑类型（否则零样本变分布外）；③ 拥堵特征匿名化。

## 3. 学习算法：SA-GRPO（结构感知群体相对策略优化）

> ⚠️ **状态（2026-09-29）**：本节的树式分层方案已被 M6 实证否决（树 372.5 ≈ flat 371.05，无增益）；保留作为"当时的设计记录"。现役算法路线见 progress-log §7/§8。

### 3.1 动机与谱系位置

每决策时刻的联合动作空间为**异质乘积**（分批×排产×物流）且**层级条件耦合**——均匀组内采样时，优势在联合空间不可比、估计方差大（难度三维度定义见 §1.1）。**必须与以下逐一对比（等预算）**：[11]GRPO、[14]F-GRPO（两阶段分解）、[17]MS-GRPO（子组多重度优势）、[8]BPPO（对比对筛选）、Dr. GRPO（去 std 化，难度偏置修正）、RLOO（留一法基线，Ahmadian 2024）；参考恒等式 arXiv 2607.00152（GRPO/Dr. GRPO/DAPO = 同一数字的三种操作；静默组率 p^G+(1−p)^G）。

**精读新增四家（2026-09-04 事实卡，见《citation-cards.md》）**：
- **[23]BranchGRPO（ICLR 2026）——同机制、不同分层维度**：它=生成时间/深度维度，我们=决策层级因果链维度（§3.5 须写"维度正交"）；其"无偏+严格更小方差"定理与我们同构，其树式实现/逐深度归一化是我们 §3.4 的规范化参照（见"引用 hook：摘要 16% 与 Table 1 终值 +2.5% 不符，引用取 +2.5%/收敛 2.2×"）；
- **U-统计量理论（arXiv 2603.01162，Zhou et al.）**：GRPO 梯度=二阶 U-统计量，MSE=trace[Σ_oracle]/G+O(G⁻²)；**G*=√(c₃/c₁) 为数据+模型几何决定的常数**（不随预算/迭代/学习率）；"基线只依赖 X"判据——见 §3.3；
- **EBPO（arXiv 2602.05165，Meta）**：跨 prompt 贝叶斯收缩（S=(σ²/G)/(σ²/G+τ²)），与我们同一 LoTV 恒等式但**分层维度不同**（它们=prompt，我们=链内层级）；Theorem 3.2 依赖二元全零奖励——我们连续 makespan **无该失效模式，域不适用**；其 G=32 时收缩收益反转（62.41 vs 62.91）→ 层组大时局部基线已足，无需全局收缩（与"层内归一化自身足够"互证）；
- **[7]Order-Invariant（ICML 2026）**：**每实例独立训练、无跨实例泛化**；附录 Q：critic 版大多不优于标准版——支撑"无 critic"立场。

### 3.2 机制

1. **分层条件采样**：按 π=π_B·π_S·π_L 采样 G 组完整决策链；
2. **层级组归一化**：每层对该层条件随机量做组内相对优势归一化 → 按 LoTV 剔除层级间共享分量 Var(E[A|hierarchy])；
3. 无 Critic（对比对象为 **PPO**：显存 −30%–50%；对 GRPO 只声称"组成本不变"）。

**机制表述（精读修订，2026-09-04）**：层级 = **条件均值塔** E[r|x]、E[r|x,b]、E[r|x,b,s] 之差（正交分量，LoTV 直接对应）；每个分量的组内归一化**与 BranchGRPO 的"逐深度归一化"机制同构、分层维度不同**（它们=树深/"same noise level"，我们=决策层级/"同层级条件结构"）；分量合法基线判据 = **只依赖该层条件变量、对被归因样本条件独立**（U-统计量理论 Cor.5 判据）；"每步发一组"使优势时序局部化——与 BranchGRPO "process-dense credit signals"（防晚期小方差步主导）同构互引。

### 3.3 定理（含条件形式——投稿必须按此写）

**命题（条件化，树式版）**：记三层条件分支树 π=π_B·π_S·π_L；深度 d 节点奖励 r̄_d 取子树均匀融合（无偏，Var=σ²(d)/|叶(d)|，BranchGRPO 附录 B.2 同构）。在 (i) 层级独立采样（各层条件采样间无共享随机源）、(ii) 每层归一化（组 = 该深度全部节点，跨父级聚合，BranchGRPO Eq.4 同构）、**(iii) 各层条件策略非退化**、**(iv) 等预算（树总链数 G·J² = 对照 GRPO 的总链数）** 下：
- **层基线合法性判据**（借 U-统计量理论："基线只依赖该层条件变量、对被归因样本条件独立"）：E[r|x]、E[r|x,b]、E[r|x,b,s] 均满足——层 d 基线是上层条件变量的函数；
- **方差级结论**：SA-GRPO 组相对优势估计器 MSE = trace[Σ_层级]/G + O(G⁻²)，Σ_层级 的层间分量 = LoTV 剔除掉的 Var(E[A|hierarchy])（= 相对均匀 GRPO 的缩减量）；首项为 oracle 投影、残差按 G⁻² 退化（U-统计量理论 Thm.2 的结构）；
- **声明范围（硬性）**：只声明**方差/MSE 级**比较，以及经 U-统计量理论 Lemma 6 通道的**有限样本子优上界**（"子优上界唯一受控于梯度估计器 MSE"）；**不声称**"严格更小的子优间隔/性能更优"（该文自认：更紧上界 ≠ 严格更优，须分布刻画）；
- **退化反例**：层内确定性 → 等号；任一层完全由上层决定 → 该层分量方差为 0（归一化退化）。

**有限样本界开写时的简化假设清单**（照列 U-统计量理论自认的 gap）：① 单步 SGD 分析（不含 Muon 等现代优化器）；② 无序列长度归一化（我们的动作是原子决策、无长度维度——比 LLM 情形默认更好，但须注明奖励有界）；③ 主定理用纯净版（无奖励标准化/IS/KL），实用版另列；④ 固定策略回归评估，优化轨迹收敛性经其 Lemma 6 通道连接而非另行证明。

**与 Dr. GRPO 关系的必写段**：层级细分使低层组 σ 更小 → 放大其指出的难度偏置；给出"分层 vs 去 std 化"的讨论与实验。

### 3.4 伪代码

```
for each iter:
  for each 决策时刻:                     # 事件驱动触发
    x ← 特征编码(s_t)
    # —— 三层条件分支树（BranchGRPO 式结构；层=树深，组=同层节点；内部节点为虚拟聚合，
    #     不产生额外采样成本——总链数 = 对照 GRPO 的总链数，等预算成立）——
    第1层 分批:  b_1..b_G ← iid π_B(·|x)                          # G 个节点
    第2层 排产:  对每个 b_g: s_{g,1..J} ← iid π_S(·|x,b_g)          # G×J 个节点
    第3层 物流:  对每个 (b_g,s_{g,j}): l_{g,j,1..J} ← iid π_L(·|x,b_g,s_{g,j})   # G×J×J 个叶
    后端评估 ← 每条叶链（SimPy 单一后端；拥塞参数配置见 §4.2）→ 叶奖励 r_{g,j,k}
      # 若不分支（J=1）：退化为均匀 GRPO——即对照组，等预算同口径
    子树融合: r̄(节点) ← 均匀融合后代叶奖励（无偏，Var=σ²/|叶|，BranchGRPO 附录 B.2）
    层内 z 化: μ_d,σ_d ← 深度 d 全部节点（跨父级聚合，BranchGRPO Eq.4 同构）
      Ã_B ← (r̄(b_g) − μ_B)/σ_B
      Ã_S ← (r̄(s_{g,j}) − μ_S)/σ_S
      Ã_L ← (r_{g,j,k} − μ_L)/σ_L     # 层基线合法性：只依赖该层条件变量（§3.3）
    θ ← θ + α·(∇ℓ(π_B, Ã_B) + ∇ℓ(π_S, Ã_S) + ∇ℓ(π_L, Ã_L))   # 分层更新（无 critic）
```

### 3.5 与既有"分层/层次"概念的区分（名称保卫，五家对照）

| 工作 | 它们的"分层" | 谱系 | 与我们差异 |
|---|---|---|---|
| GFJSPT-MMRS（SWEVO 2025）| 四子决策层动作分解 + 分层奖励 | D3QN（值函数系）| 动作/奖励结构分解，critic 系；其"分层"= 四子决策层**规则抽象**（|A|=9×10×2×6=1080 复合动作）+ 奖励的**时域**局部/全局，无条件策略、无组内优势；**"节能 ≤18.6%"未标注实例/对位基线，引用须谨慎**（[35] 卡）|
| MADAPPO（C&OR 2026）| 两阶段分层决策（工件→机）+ 新型优势估计 | 双智能体 PPO + GNN | **条件链分解先例**（π²:S×A¹→Δ(A²)——先于我们做条件策略链，[37] 卡）；优势=双值网络 GAE + 批内标准化（critic 系），非组内相对；**有链无组、无 LoTV 归因**、无运输/几何信息（原文假设"不考虑运输效率"）|
| Shi et al. Nested Hierarchical DRL | 嵌套层次控制器 | DQN 系 | 控制器分层 ≠ 组结构分层 |
| Luo et al. 分层多智能体 PPO | 目标/工件/机器三类智能体 | 多智能体 PPO | 智能体分工 ≠ 层级组归一化 |
| **Ours SA-GRPO** | **组结构上的层级条件采样 + 层级组内相对优势归一化** | GRPO 系（无 critic）| 唯一把"因果链层级"写入组定义并用 LoTV 证明方差收缩 |

**定稿句**：既有"分层"均为**动作空间 / 决策流程 / 控制器**维度的分解（值函数或智能体系）；SA-GRPO 的分层发生在**组（采样与归一化）结构**维度，并以层级共享分量剔除为理论依据——两者正交，不可混称。

> ⚫ **2026-10-06 更正：布局改为单一参数化的二维网格，拓扑变化已删除。**

### 4.2 仿真后端（定版：SimPy 单一后端，无物理库）

> 2026-09-04 二轮决策：算法论文定位 → 环境只需测试台，物理/碰撞库全部移除。建模一致理由：真实 AGV 车队用 zone request/allocate 交通管制避免碰撞（碰撞被"预防"而非"物理修复"），故不适配 pymunk/PyBullet 式自由运动碰撞模型；调度决策粒度为数十秒级，亚秒级几何细节对算法是噪声（对应"RCS 托管低级避障"边界声明）。

### 4.3 三层域随机化（DR）

① 参数层（高斯：加工时间/车速/传感器延迟——注意**只适用于连续参数**）② 事件层（**随机过程如泊松故障**，非高斯）③ 拓扑层（布局采样器）。**just-enough DR 窗口**：噪声幅度扫描曲线。

> ⚫ **2026-10-06 更正：删去 ③ 拓扑层。** 布局现为**单一参数化网格**、拓扑变化已移除（spec §3.2；跨布局泛化已砍，spec §1.1），
> 故随机化只剩**两层**：① 参数层 ② 事件层。上面的"三层"与"拓扑层（布局采样器）"作废。
