## 0. 记号与设置

> ⚠️ **状态（2026-09-29）**：下面的记号体系（塔分量 Δ_d、树式采样、逐层 z 化）作为**分析工具**仍成立；其中"树式估计器"实现外壳已被实证否决（方差结构 ratio<1 观测到，但不转化为性能增益）——使用时只作诊断，不得据此声称性能优势。

- 决策点局部状态特征 x（§2.2 编码器输出）；层策略 π_1=π_B(·|x)，π_2=π_S(·|x,b)，π_3=π_L(·|x,b,s)，θ=(θ_1,θ_2,θ_3)。
- 动作链 a=(b,s,l) ~ π_θ(·|x)；奖励 r = R(x,a;ω)，ω = 环境/扰动流随机性（机器故障、AGV 故障、加工波动、拥堵——§4.2 SimPy 后端）。
- **条件均值塔**：m_0(x)=E_ω[r|x]；m_1(x,b)=E_ω[r|x,b]；m_2(x,b,s)=E_ω[r|x,b,s]。
- **正交分量**：Δ_1 = m_1−m_0；Δ_2 = m_2−m_1；Δ_3 = r−m_2。
- **LoTV 分解**：Var(r|x) = Var(Δ_1|x) + E[Var(Δ_2|x,·)] + E[Var(Δ_3|x,·)]（塔分解的标准恒等式；✏️ EBPO Prop 3.6/3.8 用相同恒等式，可引为"组归一化分析中的标准工具"，但分层维度不同——它们跨 prompt，我们跨层级）。

**树式采样**（§3.4 伪代码）：
- b_1..b_G ~ iid π_1(·|x)；对每个 b_g：s_{g,1..J} ~ iid π_2(·|x,b_g)；对每个 (b_g,s_{g,j})：l_{g,j,1..J} ~ iid π_3(·|x,b_g,s_{g,j})；叶链数 T = G·J²。
- 节点融合：r̃_1(g)=(1/J²)Σ_{j,k} r_{g,j,k}；r̃_2(g,j)=(1/J)Σ_k r_{g,j,k}（✏️ BranchGRPO 附录 B.2：均匀融合**无偏**、Var=σ²(d)/|叶(d)|——✅ 逐条可用）。
- 层内标准化（✏️ BranchGRPO Eq.4 同构，分层维度不同——我们=决策层级，它=去噪深度）：μ_d、σ_d = 深度 d 全部节点（跨父级聚合）；Ã_1(g)=(r̃_1(g)−μ_1)/σ_1；Ã_2(g,j)=(r̃_2(g,j)−μ_2)/σ_2；Ã_3(g,j,k)=(r_{g,j,k}−μ_3)/σ_3。
- **梯度分量估计器**：ĝ_d = (1/|N_d|) Σ_{n∈N_d} Ã_d(n) ∇_{θ_d} log π_d(a_d(n)|·)，d=1,2,3；SA-GRPO 更新 = Σ_d ĝ_d（无 critic；每层只用本层分量）。

## 2. 命题骨架

**P1（无偏/塔投影）** ✅*
A1–A5 下，Σ_d E[ĝ_d] 对应塔分量（E[ĝ_d | 层条件] = 投影到该层条件变量的梯度向）；融合无偏（BranchGRPO B.2）+ 对称化（✏️ U-stat Lemma 1 的钥匙：leave-one-out → 两两差分 → Hoeffding 对称化）——*第 2/3 层核的对称性检查见 §5-2。

**P2（MSE 主项，逐层形式）** ✅（形式）⚠️（延拓）
MSE(ĝ_d(x;θ)) = trace[Σ_d^oracle(x;θ)]/|N_d| + O(E‖∇log π_d‖²/|N_d|²)，其中 Σ_d^oracle = 以塔函数 m_d 为基线（oracle 值函数扮演者）的估计器渐近协方差×|N_d|。（✏️ 结构完全同 U-stat 文 Thm.2：首项 = oracle 投影、残差 O(G⁻²) 退化。）

**P3（层间共享分量剔除 = 收缩）** ⚠️
LoTV 使 Var(r|x) = Σ_d Var(Δ_d|x)（无交叉项，塔正交性）；均匀 GRPO 的联合优势含跨层协方差项；SA-GRPO 分层估计器对其估计的梯度主项 = Σ_d 各层 oracle 分量方差和 → 相对均匀 GRPO 的缩减量 = 塔正交化消去的跨层共享方差。**声明范围（硬性）**：只声明方差/MSE 级与经 P4 的上界；**不声明"更小子优间隔/性能更优"**（✏️ U-stat 文自认：更紧上界≠严格更优）。矩阵级 Σ_d ≤ Σ_full 是 ⚠️（闭包非扩张论证），标量 trace 级 ✅。

**P4（有限样本子优界——Lemma 6 通道）** ✅（借用）
在 A2、A5、A6 + PL 条件（‖g(θ)‖² ≥ 2μΔ(π_θ)）+ 常数学习率 η_i=β<1/(2L) 下：
E[gap(π_θn)] ≤ (1−2μβ+Lμβ²)ⁿ·E[gap(π_θ0)] + Lβ²M/(4μβ−2Lμβ²)，M = sup_θ MSE(ĝ(θ))（✏️ U-stat 文 Lemma 6 原文结构；子优界唯一受控于梯度估计器 MSE——这是我们"方差叙事→界"的唯一合法通道）。

**P5（G* 注记）** ❓
✏️ U-stat 文 Thm.7：固定预算 N=BG 下最优 G* = √(c3/c1)，且为数据+模型几何的普遍常数（不随预算/迭代/学习率）。我们三层组大小不同（第 1 层 G、第 2 层 G·J、第 3 层 G·J²）——**是否存在逐层 G*_d？** ❓ 理论开放；经验侧由消融⑨（G、J 扫描）回答。

## 5. 诚实边界清单（骨架阶段未闭环的项）

1. **跨父级聚合 vs 逐父级条件组**（⚠️ 最重要）：严格同分布只在"同父级（同 b_g / 同 (b,s)）组"下成立，但逐父级组大小 = J（J=2 时组内 z-score 只基于 2 个样本——噪声大，与 EBPO"小 G 不稳"警告冲突）；跨父级（BranchGRPO 式）组更大、可标准化，但与 A5 的严格判据差一步（它们用"同噪声水平/同深度"论证可比性——我们对应"同层级条件结构"，为类比论证非严格定理）。**论文选择（待定）**：主定理用"逐父级条件组"（严格，J 需≥8 才现实 → 若主实现用跨父级，则 Theorem 用**近似**口径并显式写误差项）——这是定理-实现一致性决策，消融⑧/⑨ 一起定。
2. **第 2/3 层核对称性**（⚠️）：层 1 核 h(b,b')=(1/2)[∇logπ_1(b)−∇logπ_1(b')]·[m_1(b)−m_1(b')] 是对称核 ✅；层 2/3 的"核"定义在条件分布随上层变化的 (b,s)-对 / (b,s,l)-对上——对称化要求逐父级同分布，回到 5-1。
3. **扰动流独立性（A1 实现）**（❓ 环境侧）：每叶链独立 ω（独立 SimPy 种子）vs 同决策点共享一条扰动流（跨叶共享随机源 → 层间/链间相关性→ LoTV 分解的"无共享随机源"条件被破坏、层分量纠缠 ω）。**推荐**：每叶独立 ω（A1 满足），共享流版本作为消融⑨的一个变量（测量 A1 违反的代价）。
4. **Σ_d 矩阵级 ≤ 关系**（⚠️ 待证）：建议论文只报标量 trace 级。
5. **逐层 G***（❓ 见 P5）。
6. **EBPO 不适用记录**：其 Thm.3.2（饱和组救梯度）要求二元全零奖励；我们连续 makespan 无此模式；其收缩方向（跨 prompt 借全局）与我们（链内层级剔除）正交（✏️ citation-cards.md 批1 续·EBPO 卡）。
7. **声明纪律**：全文只出现"方差/MSE 级 + P4 上界式"，凡出现"更优/提升"一律换为实验侧数字。
