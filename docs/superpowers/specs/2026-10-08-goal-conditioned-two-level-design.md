# 目标条件化双层架构 —— 设计记录

> **状态**：设计定稿，**未动工**。2026-10-08。
> **来源**：Gemini 提出的顶层改造方案（用户转述）→ 本仓逐项核对 → 用户重构下层为三 agent → 本轮定稿。
> **定位**：用户裁定先走应用路线；约束缺口那条（原 B）暂缓。

---

## 0. 一句话

**顶层每 ΔT 输出三个中间目标 `g`；下层三个 agent（生产 / 物流 / 资源）各自在自己的触发点上决策；四者的信用都来自同一个"从同一状态采 N 个目标"的组相对优势。**

---

## 1. 架构

```
实例 + 布局
    │
    ▼
┌──────────────────────────────────────────────────────────┐
│ Transformer 编码器                                         │
│   token = 机台 · 作业 · AGV · 区段（类型嵌入 + 特征）        │
│         + 最近 K 个事件（滑窗 token）                       │
│   输出 Z_t：逐 token 隐向量                                │
└────────┬──────────────────────────────┬──────────────────┘
         │ 全局池化                      │ 逐 token（各自 attend 自己那摊）
         ▼                              │
┌──────────────────────────┐            │
│ 【顶层】π_OA              │            │
│  输出 g_t（3 维连续）      │            │
│  时机：每 ΔT / 宏观事件    │            │
└──────────┬───────────────┘            │
           │ g_t ───────────────────────┤
           ▼                            ▼
┌──────────────────────────────────────────────────────────┐
│ 下层三个 agent（各自触发点独立）                             │
│                                                          │
│  ┌─ PA（生产）── 机台侧 ──────────────────────┐            │
│  │   触发：工序可上机                          │            │
│  │   动作：12 条复合规则选 1（受 g 偏置）       │            │
│  └────────────────────────────────────────────┘            │
│                                                          │
│  ┌─ LA（物流）── AGV 侧 ──────────────────────┐            │
│  │   触发：运输任务生成                        │            │
│  │   动作：3 条 AGV 规则选 1（受 g 偏置）       │            │
│  └────────────────────────────────────────────┘            │
│                                                          │
│  ┌─ RA（资源守护）── 资源生命周期 ─────────────┐            │
│  │   头 1 · 充电：触发 = AGV 待命              │            │
│  │              动作 = {继续待命, 去最近桩}     │            │
│  │   头 2 · 保养：触发 = 机台完工、下一件未上机 │            │
│  │              动作 = {正常生产, 主动保养}     │            │
│  └────────────────────────────────────────────┘            │
└──────────────────────────────────────────────────────────┘
           │
           ▼
     段末结算 Y^i  →  A^i = (Y^i − mean) / std
     四个 agent 共用这一个优势
```

**agent 数 = 4（顶层 1 + 下层 3）· 网络数 = 4 · critic 数 = 0**

## 2. 四个 agent 的规格

| Agent | 管什么 | 触发点 | 动作空间 | 受 `g` 影响 |
|---|---|---|---|---|
| **OA**（顶层） | 全场的运行体制 | 每 ΔT / 宏观事件 | **3 维连续** | — |
| **PA**（生产） | **机台** | 工序可上机 | **12** | ✅ 偏置 |
| **LA**（物流） | **AGV 派车** | 运输任务生成 | **3** | ✅ 偏置 |
| **RA**（资源） | **资源生命周期** | 见下 | **2 + 2** | ❌ |

**RA 的两个头：**

| 头 | 触发 | 动作 | 依据的观测量 |
|---|---|---|---|
| **充电** | AGV 待命 | {继续待命(0), 去最近桩(1)} | 电量、桩占用 |
| **保养** | 机台完工且下一件未上机 | {正常生产(0), 主动保养(1)} | 役龄 / 保养间隔 |

**PA 的 12 条规则 = 4 × 3：**

```
作业选择：SPT · EAJ · SRPT · EDD      ← EDD 是新增的（原 9 条里没有交期规则）
机台分配：SMPT · MINU · EAM
```

## 3. 顶层输出 `g_t`

$$g_t = \big[\ \theta_{wip},\ \theta_{otr},\ \theta_{agv}\ \big] \in [0,1]^3$$

| 分量 | 含义 | 观测量 | 覆盖 |
|---|---|---|---|
| `θ_wip` | 在制品上限 | 缓冲区积压 | **约束 ②** |
| `θ_otr` | 目标交期达成率 | 按时完工比例 | **约束 ⑧** |
| `θ_agv` | AGV 周转率目标 | 单位时间完成的运输任务数 | 物流侧产出 |

**全部是比例 ⟹ 尺度无关 ⟹ 换实例定义不变。**

### 注入方式 —— **统一成一种机制**

```
logits(PA 的 12 条) = base_PA(Z_t) + B_PA · g_t
logits(LA 的 3 条)  = base_LA(Z_t) + B_LA · g_t
```

- `B_PA` = `12 × 3` 可学矩阵，`B_LA` = `3 × 3`
- **`g` 就是规则打分上的线性偏置**
- `B` 的第 j 列 = "第 j 个目标把哪些规则往上抬" ⟹ **可解释**

**⚠️ RA 不受 `g` 影响** —— 它的决策是资源自省，和全场的生产/物流节奏无关。

### 为什么是"中间目标"

| | 最终目标 | 中间目标 |
|---|---|---|
| 例 | makespan · 能耗 · TWT | WIP · 交期达成率 · AGV 周转率 |
| 何时可知 | **回合末**（稀疏） | **段内随时可测**（稠密） |

> **顶层的活儿：把期末那个稀疏目标，翻译成段内可执行的稠密目标。**
> **没有这一层，下层只拿得到一个回合末的数 —— 那是信用分配灾难。**

## 4. 组与优势

```
在顶层决策点 t：
  从同一状态 s_t 采 N 个目标            g¹ … g^N
  各跑 ΔT：
      g¹ → 三个下层 agent 各自决策 → Y¹
      ⋮
  ────────────────────────────────────────
  A^i = (Y^i − mean(Y)) / std(Y)
```

| 谁 | 更新式 |
|---|---|
| **OA** | `logp(g^i) × A^i` |
| **PA** | `(Σ logp_PA) × A^i` |
| **LA** | `(Σ logp_LA) × A^i` |
| **RA** | `(Σ logp_充电 + Σ logp_保养) × A^i` |

**无 critic。**

**`Y^i`** = 段末的多目标综合收益（makespan 降幅 + 能耗降幅 + TWT 降幅 的加权）。

---

## 5. 训练循环

```
for 每个顶层决策点 t:
    1. 从 π_OA(·|Z_t) 采 N 个 g
    2. N 条链各跑 ΔT（同种子 + 同前置动作，保证起点相同）
    3. 段末结算 Y^i
    4. A^i = (Y^i − mean) / std
    5. 四个 agent 全部用 A^i 更新
    6. 选一条链继续
```

---

## 6. 成本

```
成本 = 顶层决策次数 × N × ΔT = (T / ΔT) × N × ΔT = N × T
```

**⟹ 成本只由 `N` 决定，与 `ΔT` 无关。**

**可以和 `ΔT` 解耦自由选择**（想适应快就选小，想决策稳就选大）。

**参照：既有 `G=8` 一步 MK01 实测 18.2 s、MK10 86–94 s。**

## 7. 约束清单 —— 十条 → **六条**

| 约束 | 状态 | 靠什么 |
|---|---|---|
| ① 拥堵 | ❌ **去掉** | 省掉区段管理的工程量；代价是几何失去"动态"落脚点 |
| **② 有限缓冲** | ✅ **留** | 顶层 `θ_wip` 给目标 + 候选掩码 |
| **③ 机障** | ✅ **留** | **外生扰动**（不可决策，只能承受） |
| ④ 返工 | ❌ **去掉** | 随机、无决策点、无目标可设 |
| ⑤ 换型 | ❌ **去掉** | 实现是"按作业、固定 2 min"，太粗；要做扎实得先加"家族"语义 |
| **⑧ 交期** | ✅ **留** | 顶层 `θ_otr` 给目标（PA 的规则集加了 EDD） |
| **⑨ AGV 故障** | ✅ **留** | **外生扰动**（Shi 2025 的主打，保留才能和他们比） |
| ⑩ 异构车队 + 拼批 | ❌ **整个去掉** | 含车队同构化（所有车同容量同速度） |
| **⑪ 充电** | ✅ **留** | **RA 充电头决策** |
| **⑫ 保养** | ✅ **留** | **RA 保养头决策** |

### 六条约束是怎么"被处理"的

| 类型 | 约束 | 说明 |
|---|---|---|
| **被决策** | **⑪ ⑫** | RA 的两个头 |
| **被目标驱动** | **② ⑧** | 顶层的 `θ_wip` / `θ_otr` 给目标，下层的规则响应 |
| **外生扰动** | **③ ⑨** | 不可决策，策略只能承受 |

**⟹ "被策略直接决定"的只有两条（⑪⑫）。论文里必须如实写，不能说成"六条都有决策"。**

## 9. 已知问题（诚实记录）

### 9.1 ⚠️ 共享 `A^i`：对下层不是一个"干净的组"

**组的两个变异来源：**

1. `g^i` 不同 ⟹ 下层行为被条件化到不同目标
2. 下层自己采样的随机性

**对顶层：干净**（组就是 N 个 `g`，标准 GRPO）。

**对下层：无偏，但方差大，且会稀释信号。**

- **无偏**：策略梯度的基线可以是**状态的任意函数**；对下层而言 `g` 是状态的一部分 ⟹ 合法
- **但**：如果 `A^i` 主要由 `g^i` 的好坏决定，下层学到的是"哪个 (状态, g) 上下文好"，**而不是"我哪个动作好"**

**严重程度取决于 `g` 对行为的影响幅度。**
**⚠️ 顶层训练早期探索范围大 ⟹ `g` 变异大 ⟹ 稀释最严重的时候正是下层最需要信号的时候。**

**修法：**

| 修法 | 代价 |
|---|---|
| 加大 N | 成本线性涨 |
| 双层组（内层固定 `g` 采 N_low，外层 N_high 个 `g`） | 成本 `N_high × N_low × T`，**很贵** |
| 接受 | 靠共享编码器 + 多训 |

**⟹ 起步接受，把"加大 N"当调参。但论文里必须主动说明，不能装作不存在。**

### 9.2 RA 的数据量（已核算，**不是问题**）

**曾误判为"稀疏"，实际按仿真量算：**

| RA 的头 | 每 episode | **每 epoch（×N=8）** |
|---|---|---|
| 保养 ⑫ | ~40 | **~320** ✅ |
| 充电 ⑪ | ~10–30 | **~80–240** ✅ |

**⟹ 不稀疏。**

### 9.3 `g` 到 RA 的因果链断了

**RA 不受 `g` 影响 ⟹ 顶层管不到它。**

**说辞**：现实里保养/充电本来就不归调度室管（设备科自决）。**这个组织映射能用，但要写出来。**

### 9.4 「动作空间纯净」这个说法

**PA/LA 是"从固定规则集里选"（超启发式决策），RA 是"做不做"（直接控制）。**

**⟹ 两者"纯净"的方式不同。** 说"三个 agent 各自纯净"可以；说"它们的动作空间同类"就不对。

## 11. 创新评估（诚实版）

**逐件看，没有一件是新的：**

| 层 | 出处 |
|---|---|
| 子目标 HRL | FeUdal RL（Dayan & Hinton 1993）· FeUdalNets（Vezhnevets et al. ICML 2017）· HIRO（Nachum et al. NeurIPS 2018） |
| 宏观步 | options framework（Sutton, Precup, Singh 1999） |
| 下层规则选择 | selection hyper-heuristic（Burke et al. JORS 64(12):1695–1724, 2013） |
| 组相对优势 | GRPO（DeepSeekMath, 2024） |
| 异构 token Transformer | 标准 |

**唯一可能的贡献（是**论断**，不是方法）：**

> **"在分层结构中，免 critic 的组相对优势消除了 MAPPO 的 critic 非稳态。"**

- 对照：同架构、同编码器，**MAPPO vs GRPO**
- 测：训练稳定性 · 收敛速度 · 扰动下最终业绩
- **⚠️ 可能有人做过（GRPO 是 2024 年的），未查**

**评分**：方法新颖性 **低** · 发现新颖性 **中** · 域新颖性 **低** · 工程完整度 **高**。

**⟹ 现状约当**一区应用论文**（AEI / IJPR / C&IE 可能够，但不会是亮点）。**

**另一条路（暂缓）**：约束处理在高层 —— 唯一有外部文献证据的缺口
（Juárez et al. *AI Review* 59(2):80, 2026 §5.1.6 明说 open；21 种措辞 × 13,456 条记录扫描，约束激活报告零命中）。
