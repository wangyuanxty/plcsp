# 开放问题：**一个 12 路的分类头训不动**

> 写给外部求解者。所有数字都是实测读数，不是推断。日期 2026-10-11。

---

## 0. 一句话

**环境是一个 SimPy 写的 FJSP+AGV 调度仿真器。策略是「4 层 transformer 的输出接一个 12 路的分类头」，
用 REINFORCE（组内 z 化）训练 —— 它训完仍然比「直接固定用最好的那条规则」差。**

⚠️ **下面 §2.1 与 §2.2 的读数里，transformer（编码器）是**冻结在随机初始化**上的**
（我的探针里手动冻的，理由是想把被测对象缩到最小）。
**而仓里真实的训练路径不冻** —— `a_main.py` / `q1_flat.py` / `hrl/flat.py` / `hrl/train.py`
四处都是 `torch.optim.Adam(net.parameters())`，**编码器一起训**。
⚠️ **这两件事必须分开看**：§2 的读数都带「冻结」这个前提。

## 1. 最小复现的设定

**环境**：柔性作业车间 + AGV（MK01：10 工件 × 6 工序 = 60 工序，6 机台，3 AGV）。
每一局跑完约 55 个「派工」决策点。

**数据流**：

```
tok  (20 token × 8 维)              ← 6 机台 + 10 工件 + 3 AGV + 1 全局，四段各补齐到 8 列
  ↓ 4 层 transformer（分段投影 + 类型嵌入 + 全连接注意力，pre-LN）  ← 参数约 106 万
z  (20 × 128)
  ↓ pooled = z.mean(dim=1)          ← 20 个 token 取平均 → 128 维
  ↓ Linear(128→64) + GELU + Linear(64→12)   ← 约 8300 个参数
输出：12 路 logits（12 条复合调度规则）
```

**训练时**（§2.1/§2.2 的读数用的是「只训最后那个头、transformer 冻结」的版本）：

- 被更新的参数：**只有最后那个头**（约 8300 个里属于 PA 的那约 780 个）
- 冻结：transformer（约 106 万参数）、trunk、其他两个头
- 动作：12 条复合调度规则里选 1 条（= 4 个工件规则 × 3 个机台规则）
- 规则在**每个决策点重采一次**（一局采 55 次）
- 回报：**整局**标量化 `R = Σⱼ wⱼ(−fⱼ)`，`f = (makespan, energy, tardiness)`，等权、min–max 归一
- 优势：**每步跑 6–8 条链，组内 z 化 `Âᵢ = (Rᵢ−μ)/σ`**（每条链一个标量，乘到该链全部 55 个决策的 logp 上）
- `loss = −Σᵢ Âᵢ · Σₜ logp(a_{i,t})`，Adam，`lr = 1e-3`

**参考水平**：同一实例、同一场景，12 条规则各自**固定**跑整局的实测 makespan

```
EAJ+EAM   = 70.1   ← 最好
EAJ+SMPT  = 76.5
EAJ+MINU  = 88.1
SPT+SMPT  = 107.0
SRPT+MINU = 129.7  ← 最差
```

## 2. 读数

### 2.1 纯前向（没训练）：**55 个不同状态 → argmax 只有 2 种**

同一条链的 55 个决策点，状态两两不同：

```
tok        互不相同  55 / 55
pooled     互不相同  55 / 55
logits     互不相同  55 / 55
argmax     **只有 2 种**
```

跨状态成对余弦：`tok 0.701 → pooled 0.931 → logits 0.980`。

**取两个最不相似的状态**（`tok` 余弦 0.295），逐级余弦：

```
原始 tok（展平）             0.2952
分段投影 + 类型嵌入            0.5725   ← +0.277  ★
attention 第 1 层            0.6432
attention 第 2/3/4 层        0.6274 / 0.6473 / 0.6549
pooled（20 个 token 取平均）  0.6880   ← +0.033
Linear(128→64)             0.7354
GELU                       0.7844
输出 logits（12 路）          0.9430   ← +0.159  ★
```

**输入差 45°，输出只差 11°。**

两处跳变的拆解：

- **分段投影那一跳**：`nn.Linear(7, 128)` 带 bias。输入是 7 维、值域 `[0,1]` ⟹ `‖Wx‖ ≈ 0.6`；
  bias 按 `±1/√fan_in` 初始化 ⟹ `‖b‖ ≈ 2.5`，**是信号的 4 倍**，而且**该段所有 token 共用**。
  实测 bias 占输出范数 **41–55%**。**置零后这一跳从 +0.25 降到 +0.03。**
- **输出头那一跳**：`W·gel` 本身就 0.9398（bias 只贡献 0.003）。
  `‖W·差‖/‖差‖ = 0.154` 而 `‖W·共同‖/‖共同‖ = 0.310` ——
  这个随机 `W` 在「状态差异方向」上的增益只有各向同性期望（0.433）的 1/3。
  **换一个随机 12×64 矩阵只推到 0.814。** ⟹ 更像随机性，不像结构错。

### 2.2 训练后：**比最好的固定规则差**

| | |
|---|---|
| 5 个初始化种子，各训 16 步 | 训后 makespan = **89.7 / 92.2 / 93.6 / 105.5 / 107.2** |
| 最好的固定规则 | **≈ 75** |
| 55 个决策点上「主导规则」占比 | 56% / 78% / 98% / 62% / 60% |

**5/5 个种子训完都差于固定用最好的那条规则。**

（150 步 × 3 种子的复跑进行中，用来排除「16 步不够」。）

### 2.3 ⚠️ 方法学警告

**同一条份代码、只换初始化种子，训后 makespan 散在 89.7–107.2（标准差 7.2）。**
而我在调试过程中做过的绝大多数对比都是**单次运行**的 ——
**那些「某改动有效」和「某改动无效」的结论都不可信**，请忽略第 3 节里定量的部分，
只看「试过什么方向」。

## 3. 已试过的方向

| 方向 | 试了什么 | 单次读数 |
|---|---|---|
| 奖励口径 | 段回报第一分量：完成工件数 → 完成工序数 → 进度率 → 对位论文的 Δ(部分解 makespan) | 无稳定改善 |
| 优势 | 组内 z 化 / critic `R−V(s)` / critic + 优势归一化（PPO 口径） | 都退化 |
| 编码器残差 | 原为 `x = x + ln(sublayer(x))`（**非标准写法**）→ 改成标准 pre-LN | token 状态内余弦 0.90→0.49（**真 bug 修复**），**训练结果不变** |
| 上层输入 | 全局均值池化 / 段内逐列 mean/min/max / **展平 token 接线性层** | 训完都差 |
| 超参 | `lr` 1e-3 / 1e-2；步数 15–60；每步 2–8 条链 | 无稳定改善 |
| 动作空间 | 12 条规则 vs 3 条 | 无稳定改善 |
| 投影 bias | 置零 | 前向那一跳消失，训练更差 |

## 4. 与对位论文的差（**未对齐**）

**Shi et al., *Advanced Engineering Informatics* 65 (2025) 103195** —— 同题面的两层框架
（上层 OA 选目标 → PA/LA 选规则）。**它给上层的是 31 个手工聚合特征，直接喂一个小 MLP
（31 → 256 ReLU → 动作数）。没有 token、没有注意力、没有池化。**

| 它的特征 | 我们 |
|---|---|
| f2–f4 机台**利用率** `MU_k` 的 mean/min/max | ❌ 完全没算 |
| f5–f7 机台最早可用时刻 `MCT_k` 的 mean/min/max | ⚠️ 加了 3 维，但塞在 token 里被平均掉（权重 1/20） |
| f10–f12 AGV **利用率** `AU_v` 的 mean/min/max | ❌ 完全没算 |
| f13–f15 AGV 最早可用时刻 `ACT_v` 的 mean/min/max | ❌ |
| f16/f18/f19 待加工工序数 / 剩余工序数 / 未完工工件数 | 部分 |
| f20 总完工率 | ✅ |
| f21–f23 工件完工率 `CRJ_i` 的 mean/min/max | ❌（逐工件的在 token 里，聚合量没有） |
| f24–f26 最早待加工工序处理时间 `APT` 的 mean/min/max | ❌ |
| f27–f29 工件剩余工时 `RTJ_i` 的 mean/min/max | ❌ |

原文口径：

> *"**PA can only observe information relevant to the resources and scheduling tasks it manages**"*

**同题的 HA-DQN（*Complex & Intelligent Systems* 2025, 11:210）**给上层 5 个显式特征，
其中 #1 是 `CM(t)` = 当前部分解的 makespan，**且它的逐决策点奖励就是 `r(t) = −(CM(t) − CM(t−1))`。**
