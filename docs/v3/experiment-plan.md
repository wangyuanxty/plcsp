## 0. 判据（先读）

**每一项实验必须挂在一个 claim 上。挂不上的不排。**

| | 不给分 | 给分 |
|---|---|---|
| 论证 | “没人做过” | “**他们做不了，因为假设/表征排除了它**” |
| 结果 | 指标更好 | **改变了某条已有结论** |

### 0.1 v3 的当前主线

- v3 = **4 agent**：上层 **MA** + 下层 **PA / LA / RA**。
- 训练方式：**一个模型**，跨实例；**不是一个实例一个模型**。
- 主 claim：一个模型在 **MK01–10 零样本**上成立。
- 辅助 claim：留出实例、留出布局。

⚠️ **一个 seed、20 步的冒烟不是结果。**
当前 `a_multi.py` 的 20 步读数只证明流水线能跑。

### 0.2 分期（按 claim 分，不按实例数分）

| 期 | 训练 | 测试 | 能写什么 |
|---|---|---|---|
| **冒烟** | 1–2 个随机实例 | MK01 | 只写“跑通” |
| **① 主实验** | 随机实例（MK 范围），**一个模型** | **MK01–10 零样本** | 未见过实例 + 未见过布局（训练分布需覆盖 MK 范围） |
| **② 补充 A** | 6 个 MK | 4 个留出的 MK | **同分布跨实例** |
| **③ 补充 B** | 固定实例，布局 0/1 | 布局 2 | **跨布局** |
| **④ Oracle** | 每个 MK 一个模型 | 原实例 | 只作上界，不作泛化 |

⚠️ **不得把 ① 写成“逐实例训练”。**
⚠️ **不得把 ④ 写成“跨实例泛化”。**

## 1. 实验清单

### A · ⭐⭐ **主干：一个模型跨实例**

| | |
|---|---|
| **训练** | `gen_mk_like`：工件 10–20 · 机台 4–15 · 工序 3–15 · 候选 1–6 · 工时 1–19 |
| **实例数** | 预建 20 个随机实例，按步轮换 |
| **布局** | 每实例固定一个 `layout_seed`（100+i） |
| **臂** | HRL（4 agent） |
| **seeds** | **≥3** |
| **步数** | **200**（先跑通；再按 MDE 定） |
| **评测** | MK01–10，布局 `layout_seed=200+i`（未参与训练） |
| **对照** | 每个 MK 上 **36 条固定规则**的最好值（12 PA × 3 LA，同布局、同场景） |
| **记录** | 每 25 步的 greedy 评测整条曲线 |
| **判据** | **峰值**赢规则 ⟹ 能力够；**最终值**赢规则 ⟹ 收敛稳。两个分开报 |
| **状态** | ❌（20 步冒烟已通，正式未跑） |

#### A.1 对照组（必须）

| 组 | 作用 | 状态 |
|---|---|---|
| **RN** | 随机动作下界（全 agent 随机） | `repro/v3_pilot_baselines.py`；已跑 |
| **36 条 CDR**（12 PA × 3 LA） | 固定规则全集 · 每实例最好值 · Pareto 集 | `hrl/cdr.py` 已有；已跑 |
| **最好 CDR** | 主对比对象 | 从 36 条里取 |
| **NSGA-II** | 三目标元启发式 | `baselines/nsga2.py`（pymoo）；机器 only + 完整 MA+OS+AGV 已跑 |
| **MAPPO** | 多智能体 PPO · 集中式 critic · 同一动作空间 | `hrl/mappo.py` + `repro/v3_mappo.py`；**已实现 + 冒烟，正式未跑** |
| **HGS** | 已发表 DRL 基线（Moon et al., *JMS* 77:356–367, 2024） | `baselines/hgs/`；⚠️ 只做 MS，训练成本高 |
| **Exact CP-SAT** | 小实例最优值 | `baselines/exact_cpsat.py`；⚠️ `ortools` 未装 |
| **每实例 Oracle** | 10 个模型的上界 | 可选，不作泛化 |
| **Flat / CDR 臂** | 分层消融，不是外部基线 | 见 B |

**共同口径：**

- 所有组用**同一 MK 实例、同一布局 seed、同一场景**；
- 学习类基线同训练预算或在结果里注明预算差异；
- 至少 **3 seeds**；固定规则/精确解注明是否确定性；
- 三目标（MS / 能耗 / 拖期）都要报，不能只报 MS；
- HGS 的已发表数字是 MKT/车辆数口径，**不得直接并列**；要么在同仿真里重跑，要么只写“同数据、同车辆数设定”。

#### A.2 精确解基线（可选，不是竞争者）

`baselines/exact_cpsat.py` = **OR-Tools CP-SAT** 精确求解器。

| 项 | 口径 |
|---|---|
| 用途 | 给策略一把**认证过的尺子**：`(J_policy − J*)/J*` |
| 模型来源 | Yao, Liu, Li, Gao. *Constraint Programming for AGV and Machine Integrated Scheduling Problem in Flexible Manufacturing System.* **IEEE Transactions on Automation Science and Engineering 23:2378–2390, 2026.** |
| 覆盖范围 | **仅 `REPORT_TIERS["A-MKT"]`**：十机制全关，只剩 FJSP + 行程时间矩阵 |
| 目标 | **仅 makespan** |
| 实例 | **仅矩阵口径**（`load_mkt(...).base`） |
| 不能覆盖 | v3 的几何布局、故障、保养、拖期、有限缓冲 |

**两个读数必须分开报：**

| 量 | 含义 |
|---|---|
| `dual_bound` | **认证的下界**；对任何策略都成立 |
| `objective` | 求解器找到的最好可行解；**不是认证的**，除非状态是 `OPTIMAL` |

⚠️ **主实验（随机实例 → MK 零样本）不需要它** —— 它不覆盖 v3 的机制。
⚠️ 只在“小实例最优性间隙（A-MKT 档）”这一条 claim 上使用。
⚠️ `ortools` 默认解释器**未装**；不装就不跑，论文里如实写“未做精确解对比”。

### B · ⭐⭐ **分层消融**

| 臂 | 上层 MA | 下层 |
|---|---|---|
| **1 · HRL** | 选规则 | 调参 |
| **2 · Flat** | —— | 自选规则 + 自调参 |
| **3 · CDR 臂** | 固定规则（不条件在状态） | 调参 |

**训练/评测协议同 A。**

| 判据 | 结论 |
|---|---|
| 臂 3 ≈ 臂 2 | 上层多余 ⟹ v3 立论垮 |
| 臂 1 明显好于臂 3 | 上层状态依赖有用 |
| 臂 1 ≈ 臂 3 但都好于臂 2 | 收益来自“拆出规则选择”，不来自状态依赖 |

### C · ⭐ **参数化消融**

| 臂 | 参数 |
|---|---|
| 参数化 | `α, β, γ, A` 自由（`σ=0.5`） |
| 退化 | `σ=0` 或 `α=β=γ=1`（= 固定规则） |

**训练/评测协议同 A。**

### E · ⭐ **收敛/稳定性**

不单独跑，从 A 的曲线读：

| 量 | 怎么读 |
|---|---|
| 不动点数 | 曲线里不同取值的个数 |
| 峰值−最终 | 差值越大越不稳 |
| 种子分散度 | 同一实例上的跨 seed 方差 |

### F · 沿用 v2 的部分（设计不变，数字重跑）

| 节 | 内容 | 说明 |
|---|---|---|
| 约束组消融 | `ABLATION_GROUPS` 五组 | 设计可沿用 |
| 机制消融 | RA 规则数、PA/LA 规则集 | RA 现为 3 条规则 |
| 敏感性 H | 同策略在扰动环境重评 | 设计可沿用 |
| 统计口径 K | 种子数、MDE、显著性 | v3 必须定 |

### G · 明确**不做**（现在）

| 不做 | 为什么 |
|---|---|
| 偏好条件化 / Pareto 前沿 | 不是 v3 的设计 |
| 分时电价 | MK01 撑不起 |
| 事件段 token | 不是当前瓶颈 |
| 每实例一个模型作为主实验 | 只能作 oracle |

## 3. 依赖与顺序

```
① 冒烟（a_multi.py，20 步）              ✅ 已通
   │
② A 主干：3 seeds × 200 步               ← 先做
   │   └─ 判据：峰值 / 最终值，两个都跟最好固定规则比
   │
③ B 分层消融（+ CDR 臂）
   │
④ C 参数化消融 · E 稳定性
   │
⑤ 补充：6 训 4 测 / 留出布局
   │
⑥ Oracle（可选）
```

**⚠️ ② 不通过（峰值都不赢规则）⟹ 停，先查为什么，别往下铺。**
