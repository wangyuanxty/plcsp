## 1. 实验清单

### A · ⭐⭐ **主干验证** —— "策略能不能稳定赢过固定规则"

| | |
|---|---|
| **对照** | **36 条固定规则里最好那条**（同配置 · 同布局，实测可得） |
| **臂** | 扁平 · 两层 |
| **配置** | MK01 · `pm_interval=30` · `target_failures=4` · **`layout_seed=0` 固定** |
| **seeds** | **≥3**（v2 的经验：1 个种子说明不了任何事） |
| **记录** | 每 25 步的 greedy 评测**整条曲线**，不只最终值 |
| **判据** | **峰值**赢规则 ⟹ 能力够；**最终值**赢规则 ⟹ 收敛稳。**两个分开报。** |
| **状态** | ❌ |

⚠️ **必须报"峰值"和"最终值"两个数** —— v2 的教训就是只看最终值会把"学到又丢掉"误读成"学不会"。

### B · ⭐⭐ **分层消融** —— "上层的规则选择有没有用"

**这是 v3 存在的理由，必须测。**

| 臂 | 上层做什么 | 下层做什么 |
|---|---|---|
| **1 · 两层** | **选规则**（MA 三个头） | 调参 |
| **2 · 扁平** | —— | **自选规则 + 自调参** |
| **3 · ⭐ 常数规则** | **输出固定的规则**（不条件在状态） | 调参 |

| 判据 | 结论 |
|---|---|
| 臂 3 ≈ 臂 2 | 上层**多余** ⟹ **v3 的立论垮** |
| 臂 1 明显好于臂 3 | 上层**的状态依赖**有用 |
| 臂 1 ≈ 臂 3 但都好于臂 2 | 收益来自"**把规则选择拆出去**"，不来自状态依赖 |

**⚠️ 臂 3 是 v2 从没跑过的那个对照** —— 它比"冻结 `g`"干净（不关通道）。

**状态**：❌

### C · ⭐ **参数化消融** —— "超参数有没有用"

| 臂 | 参数 |
|---|---|
| **参数化** | `α, β, γ, A` 自由（`σ=0.5`） |
| **退化** | **`σ = 0` 固定 ⟹ 参数恒等于 `μ`**，或直接把 `α=β=γ=1`（**= v2 的固定规则**） |

**判据**：参数化明显好 ⟹ 翘曲指数是真机制。**两者差不多 ⟹ 扔掉参数化，退回固定规则。**

**状态**：❌

### D · **σ 敏感性**（便宜）

`σ ∈ {0.2, 0.5, 1.0}` —— **只重评或短训**。

**判据**：曲线对 σ 敏感吗？**若极敏感，写进 §H 的 assumed 参数表。**

**状态**：❌

### E · ⭐ **收敛/稳定性** —— "还会不会学到又丢掉"

**不单独跑**，从 A 的曲线里读：

| 量 | 怎么读 |
|---|---|
| **不动点数** | 曲线里**不同取值的个数**（v2 的 s0 只有 4 个） |
| **峰值−最终** | 差值越大越不稳 |
| **种子的分散度** | v2 的 s0/s1 **逐位相同** ⟹ 说明它们落在同一个不动点 |

**状态**：❌

### F · 沿用 v2 的部分（设计不变，数字要重跑）

| 节 | 内容 | 说明 |
|---|---|---|
| **约束组消融** | `ABLATION_GROUPS` 五个组 | 设计可沿用 |
| **机制消融** | `④` 的 RA 规则数、PA/LA 规则集 | ⚠️ **RA 现在是 3 条规则，不是 2 路头** |
