## 5.7 P1b 能耗与约束（2026-10-03 完成）

- **能耗换成 M2 引证模型**（`plcsp/energy.py`）：机床三态 + AGV 三态 + 车间固定，参数取自 GFJSPT-MMRS。
  实测 MK10 351→**43.99 kWh**，文献同规模实例 516 min→**42.4 kWh**；比值 0.073–0.125 vs 锚 0.063–0.082。
  旧的 `energy_power`（把时间当能量）**已废弃**，活代码不再读。
- **十一约束全部接入且可独立开关**（`plcsp/env/constraints.py`，5 组消融 = 5 个配置实例，改配置不改代码）。
- **⭐ 每个约束都有 binding 实测判定**——`spec §3.3.2` 是判定表，`spec §3.3.3` 是"为什么大半不 binding"的根因。
  - **默认参数下就 binding**：只有 **⑤ 换型**（最大杠杆，−28%/−14%）
  - **默认太松、极端档强 binding**：③④⑨⑫（"参数尺度不匹配，非机制无关"）
  - **两档都不 binding**：①拥堵 ⑥模糊 ⑩异构 **⑪充电**（⑪ 是**结构性死约束**：episode 耗电 0.27 kWh ≪ 电池 2–4 kWh）
- **两条会动摇叙事的实测**：
  1. **运输不在关键路径**——n_agv=1 时单车利用率也仅 4–23%，1车→6车 makespan 仅差 −1%~+12%。
  2. **但此结论与调度质量纠缠**：MK01 跑 101 vs BKS 40，机台利用率仅约 25%，松弛是弱调度制造的。
     **必须在 P2 有像样策略后重测，不能当定论。**
- **顺带修的三处**：AGV 车速默认 1.0→**0.5**（改用已引证值）；AGV **空载段**补齐（v0 是瞬移取货）；
  τ 由 0.85 → **0.90**（P1b 模型变更后重标，误期率 26/44/65% → 20/28/48%）。
